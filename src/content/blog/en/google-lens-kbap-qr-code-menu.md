The card on your table says to scan a QR code, but it does not show any dish names. Your first task is to **open the menu's link**. Google Lens can help with that. K-Bap's menu scan is for reading a menu image and understanding recognized dishes, so it comes later if you need food context.

Here is a suggested workflow based on documented functions. It is not a test of either app's speed or recognition accuracy, and it does not assume that every restaurant uses the same ordering website.

## Open the QR link with Google Lens in Chrome

Google publishes separate QR-code instructions for [Chrome on Android](https://support.google.com/chrome/answer/15086890?co=GENIE.Platform%3DAndroid&hl=en) and [Chrome on iPhone](https://support.google.com/chrome/answer/15086890?co=GENIE.Platform%3DiOS&hl=en).

**On Android:** Open a new Chrome tab, tap the Lens icon in the search bar, and choose **Search with your camera**. Fit the QR code inside the box, then tap the link that appears.

**On iPhone:** Open a new Chrome tab and tap the Lens icon in the search bar. Position the QR code inside the highlighted box, then tap the displayed link.

These are Chrome instructions, not a QR mode inside K-Bap. Keep the restaurant's table card in view so you can check that you are opening the intended menu. If no link appears or the page is not the menu you expected, ask staff for help or another way to view it.

## Work out what the opened page does

Once the page loads, look for the restaurant name and any language control. Then establish whether the page is just a menu or also takes orders. Do not infer that an order has been sent merely because you opened a link or selected a dish.

If the page asks for a table number or branch, check it against where you are sitting. Follow the restaurant's instructions for submitting an order, or ask staff how they want you to order. Any confirmation should come from that restaurant's system or staff.

This is an editorial checklist for using the page you encounter, not a description of a particular live restaurant service.

## Bring K-Bap in when you need to understand the food

A QR code and a menu image are different inputs. K-Bap's current menu scan reads photographed menu text; it does not open a restaurant website by decoding the QR code on the table.

If the opened menu contains unfamiliar Korean dishes, K-Bap's [official app listing](https://apps.apple.com/us/app/k-bap/id6788635067) describes menu scanning with translated names, reference photos, and ingredient information for recognized dishes. You can select a readable menu screenshot from your photo library through the scan screen's gallery control. For that step, see [our saved-menu image walkthrough](/blog/google-lens-kbap-saved-takeout-menu/).

Save the actual menu content, not a screenshot containing only the QR code. Keep any options and prices visible when you compare the recognized result with the restaurant's page. A general dish entry does not confirm that location's serving size, recipe, or current availability.

## Keep the restaurant's order separate

K-Bap can prepare a Korean order screen to show staff. That screen does not submit a basket to the website you opened from the QR code. Our [Korean order-screen guide](/blog/show-food-order-in-korean/) explains the in-person handoff.

Before proceeding, decide which ordering method the restaurant expects: its website or a conversation with staff. If you already submitted an order on the website, tell staff that when asking a question about it so your request is not mistaken for another order.

For a QR menu, use Lens to reach the linked page. Use K-Bap when you need menu-focused context for the dishes you can see. Return to the restaurant's own ordering process to finish. [Explore K-Bap](/) for help reading your next Korean menu.
